# GovAI Nexus – React Native & Expo Mobile Application (24 Screens)

## 1. Mobile Technology Baseline
- **Framework:** React Native + Expo SDK 52+
- **Navigation:** Expo Router (File-based routing with tab and stack layouts)
- **State Management:** TanStack Query + Zustand
- **Target OS:** Android (APK / AAB) and iOS (IPA)
- **Supported Languages:** Tamil & English with instant in-app switching

## 2. Bottom Navigation Architecture
The core mobile citizen experience is structured around 5 persistent bottom tabs:
1. **Home:** Personalized feed, quick services, search bar, latest updates.
2. **Services:** Catalog of Tamil Nadu state services categorized by department.
3. **AI Assistant:** Voice & chat assistant with verified government citations.
4. **My Requests:** Unified tracking for applications and grievances.
5. **Profile:** Personal credentials, saved documents, language toggle, and consent settings.
